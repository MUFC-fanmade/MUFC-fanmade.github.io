Guide

使用指南

注册与登录

  1. 向主办方获取邀请码。
  2. 进入“登录”页面，切换到“邀请码注册”。
  3. 填写昵称、邮箱、密码和邀请码完成注册。
  4. 注册成功后回到登录表单，使用邮箱和密码登录。

提交作品

  1. 登录后进入“提交作品”。
  2. 填写标题和作品说明。
  3. 上传严格命名的文件：maidata.txt、track.mp3、bg.jpg 或 bg.png。
  4. 如有视频预览，可额外上传 pv.mp4。
  5. 提交成功后，作品会进入会场和谱面列表。

浏览、评分与评论

  1. 首页只展示最近 5 个谱面。
  2. 进入“谱面列表”可以查看全部作品，并用关键词检索。
  3. 点击作品封面进入详情页，播放器会加载谱面预览。
  4. 登录后可以对作品评分，并在评论区使用 Markdown 发表评论。
  5. 个人中心可以查看自己的作品、评分记录，并修改昵称和头像。

常见提醒

  • 邀请码错误或已使用时，页面右上角会浮现错误提醒。
  • 未登录时无法提交、评分或发表评论。
  • 上传文件名必须完全符合要求，否则提交会被阻止。
  • 头像文件不能超过 2MB，仅支持 JPG、PNG 或 WebP。
